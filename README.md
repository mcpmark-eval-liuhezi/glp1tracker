# GLP-1 Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review on **GLP-1 receptor agonists in type 2 diabetes**.

## Purpose

This repo captures the late-stage (Phase 3) recruiting landscape of GLP-1 RA trials in adults with type 2 diabetes, as registered on ClinicalTrials.gov. It serves as a durable record of:

- Currently recruiting Phase 3 studies of GLP-1 receptor agonists in type 2 diabetes, ranked by planned enrollment
- Sponsor and phase breakdowns of the overall recruiting landscape
- Per-trial tracking issues with sponsor, phase, planned enrollment, and primary completion date

## Contents

- `README.md` — this file
- Tracking issues per selected trial (NCT ID in title; sponsor/phase/enrollment/completion date in body)
- A parent summary issue with the phase and sponsor-class breakdowns as a comment

## Query basis

- **Condition:** Type 2 diabetes
- **Intervention:** GLP-1 receptor agonist
- **Status:** Recruiting
- **Phase filter for selection:** Phase 3
- **Selection criterion:** Three largest planned enrollment values
